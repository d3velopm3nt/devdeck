What happens when something is resolved
1
Something asks for a reference
A service definition, a command, or an agent's tool call. It names vault://github/devdeck-release — it does not name a value.
2
The matrix decides, then a person might
Use, Ask or None. None refuses without asking anyone. Ask blocks the agent and prompts you, and denies if nobody answers. There is no level above Use, because there is nothing above putting a value into a process without showing it to anyone.
3
Bitwarden hands over the value
Read once, held in memory, never written to SQLite and never pushed onto the log bus.
4
It goes into the process, not into the prompt
Environment or stdin, exactly as conn.rs already hands psql a password — never an argument on a command line, where every process on the machine can read it.
5
Vault writes down that it happened
Who asked, which reference, what for, and what was decided. Never the value.
