Three kinds, ranked, never mixed
Approvals
An agent is stopped mid-turn with a thread held open, on a 90-second clock. These are the only rows with a deadline, so they sit at the top and carry the countdown. Answering one unblocks an agent immediately.
Blockers
Work that cannot continue: stale context, a conflict, a branch behind origin, a failed suite. No clock, but nothing moves until you deal with them. Each links straight to the thing.
Suggestions
Everything the app noticed but nothing depends on. Always dismissable, never auto-applied, and they never bump the count colour — a badge that goes amber for “storybook isn’t running” teaches you to ignore it when an agent is actually waiting.
Scope
The panel covers the whole workspace, not the open project — an agent waiting on tyrex must reach you while you are looking at assetx. Every row carries its project badge, and clicking one switches to it.
Rows from other workspace tabs raise that tab’s dot instead of appearing here.
Open question: should approvals also raise a Windows toast when DevDeck isn’t focused? An agent that times out because the window was behind a browser is the failure this panel exists to prevent.
