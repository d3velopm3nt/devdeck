  • Team Builder returns a structured proposal with names, roles, responsibilities, and reporting lines. Invalid hierarchies show an actionable error.

  • Legacy manager and personal team records migrate to structured storage. Original files remain backups; deleted managers do not reappear from them.
  • Conversation configuration persists across reloads. Runtime sessions and CLI receipts record the launch definition. CLI settings changed after a preview require a new preview.

Known boundaries

  • Start a new discussion to use changed model/instruction settings. Existing conversations keep their launch snapshot. Manager coordination turns are separate runs so incoming messages and responsibilities stay current.
  • Conversation reload is supported. Resuming a terminated native/CLI work process is not implemented; a new work run gets a new snapshot. Historical runs are not backfilled with invented snapshots.
  • Vault coordination profiles remain distinct from reusable Workforce team organograms. Manager definitions are integrated into Library; their existing coordination graph is not automatically converted.
  • Build creates a reviewed team structure. Automatic installation/security scanning of tools and execution of a full team workflow remain separate operations.
