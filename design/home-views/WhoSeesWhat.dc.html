Two people, one app
Not a mode you flip — a different person. Which home you get is decided once, when you set the app up, and everything else follows from it. A clean page with a twelve-item rail beside it is not a clean page.
Someone using it
Home Today Team Settings
Four things. Everything else is reachable by asking, or from inside these.
Someone building it
Home Team Inbox Explorer Calendar Connections Analytics Stash Machine Settings
Unchanged. The dashboard, the logs, the terminals, the vault.
What the clean home never shows
Services, terminals, logs, git, CPU, memory, sessions, token counts, model names, the vault tree. Not because they are secret — because none of them are a thing that person came to do. Every one of them is still there for the other person.
What it says instead of a number
“One item is stuck”, not “1 blocked”. “Eight to pick up”, not “0/10”. “Nobody to do the work yet”, not “no agent named”. The counts are the same counts; the words are the difference between a dashboard and a page.
The rule that keeps it clean
One thing may want you at a time. If two managers are stuck, the page says one sentence and the second waits — a clean page that grows a list is just a dashboard with more white space. Everything queued is in Team, which is one tap away.
