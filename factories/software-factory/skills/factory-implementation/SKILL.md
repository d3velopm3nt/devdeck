---
name: factory-implementation
description: Implement an assigned software factory work item in its owned branch and provide a reproducible handoff.
---

Read the work item, acceptance criteria, repository instructions and applicable skills. Confirm branch/worktree ownership and base commit before editing. Preserve unrelated work.

For a defect, capture the failing behavior when reproducible. Follow the project's established architecture and make the smallest complete change. Run checks appropriate to the affected behavior.

Hand back the branch, HEAD commit, changed paths, commands and actual outcomes, evidence paths, limitations and remaining risks. Distinguish a passing check from an untested claim. Do not push, publish, merge or change team permissions as part of implementation.
