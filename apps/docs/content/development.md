# Terminals, commands and services

## Terminals

Open a terminal from the project or folder you want to work in. Interactive terminals run in the backend and appear as tabs. Confirm the directory before running a command.

## Saved commands

Use saved commands for repeatable actions such as building or checking a project. Give commands clear names and verify their shell and working directory.

## Services

Define long-running processes such as a development server. Start, stop or restart them and inspect status, logs, resource usage and configured ports. A service with a configured port can provide an open-in-browser action.

## Launch profiles

A profile groups services, terminals and layout so you can start a familiar stack together.

## Example

For a web project, create a service for its existing development command, set its port, start it, and inspect its logs before opening the app.

## If something fails

Check the executable is installed, dependencies are present, the directory is correct and the port is available. Use the log output as the starting point for diagnosis.
