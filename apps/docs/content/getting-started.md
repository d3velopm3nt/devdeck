# Getting started

## Install and open

Get a Windows installer from [GitHub Releases](https://github.com/d3velopm3nt/devdeck/releases). Choose the release you intend to test; beta builds can contain unfinished features.

Open DevDeck and follow the workspace setup. GitHub sign-in and a personal access token fallback are part of the onboarding work; availability depends on your build. Keep tokens out of workspace files.

## Connect your work

1. Select the workspace or state repository you want to use.
2. Open Explorer and check that your existing folders appear.
3. Add or select a project and set its local repository path.
4. Open a terminal in that project and confirm its working directory.

## Before using an AI worker

Configure the runner or provider, select the worker's skills and target, and review its permissions. A connected model alone does not establish that a local command-line runner is installed.

Continue with [workers](#agents) or the [workflow walkthrough](#workflows).
