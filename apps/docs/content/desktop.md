# Desktop and machine tools

The floating Command Widget provides quick access to commands. The documented default shortcut is Ctrl+Shift+Space and can be configured in settings.

## Layout and appearance

Dock, split, float and resize panels. Use the theme switcher to change appearance.

## Machine setup

Machine setup checks installed software and integrates with Scoop and winget. Inspect any proposed installation before proceeding.

## Updates

Use the update controls to inspect available versions. Stable and beta release channels should remain distinct; release automation and Scoop updates depend on the published release configuration.
