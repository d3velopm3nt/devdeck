Brand Voice
Build a durable voice profile from real source material, then use that profile everywhere instead of re-deriving style from scratch or defaulting to generic AI copy.
When to Activate
• the user wants content or outreach in a specific voice
• writing for X, LinkedIn, email, launch posts…
Written by someone else, and it becomes part of a worker’s instructions. Read it before you add it.
What comes in
Skills: a folder of instructions and references. Words, nothing that runs.
Agent briefs: who a worker is for a job, like marketing-agent.
What never does
Hooks: they run commands on every step a worker takes.
MCP configs and install scripts: servers come through Community one at a time, with their own grant.
Your own Claude Code setup: the library is DevDeck’s. ~/.claude is left as it is.
