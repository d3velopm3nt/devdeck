Why a list and not a search
“Find me something that does X” sounds better than it is: it ends with a model choosing whose code runs on your machine. This is a catalog anyone can add to by pull request, so a human decided each entry, and every card says what it will be allowed to do before you install rather than after.
The assistant may suggest from this list when it notices you need a capability. It cannot install one.
