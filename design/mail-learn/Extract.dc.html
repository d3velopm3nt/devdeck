What it can actually read

Extraction runs on this machine, before anything is sent anywhere. A type that cannot be read says so on the attachment rather than quietly producing nothing.

works today Images Windows OCR, already in this codebase — shots::ocr takes any image path and the screenshot watcher has used it for months. A photographed invoice is readable on day one.
works today Text, CSV, Markdown Read the file. Guess the encoding, because mail is full of Latin-1 that claims to be UTF-8.
small job Word, Excel A .docx is a zip with XML inside. No new dependency, no parser to trust — unzip one entry and strip tags.
one new crate PDF, with text Most invoices and contracts. The only genuinely new dependency on this board.
not yet PDF, scanned No text layer, so it must be rendered to an image before OCR can see it. That is a renderer, which is a much bigger dependency than a parser. Say “this looks scanned, I cannot read it” and stop.
never Everything else Archives, executables, calendar invites, anything unknown. Kept as a file, listed on the message, not read.
The rule that matters more here than anywhere else

The Stash already flags secret-shaped clips and never writes their values to disk. Attachments need the same rule and need it harder, because a scanned passport becomes searchable text the moment OCR touches it. The file was always there; the text is new, and it is the text that gets sent to a model.

flagged card numbers · ID and passport numbers · bank account and routing details · anything shaped like a key, a token or a one-time code
then keep the file, keep the fact that a document exists, and refuse to send that text to any model — the attachment says why, so a refusal never looks like a failure.
Order I would build it
1   Store the file and write file_path. Nothing reads anything yet, and the Mail page can already open an attachment.
2   Text, CSV and images. Zero new dependencies, and OCR is already proven here.
3   The secret-shape rule, before any extracted text can reach a model.
4   Office files, then PDF with a text layer.
5   Scanned PDFs, only if you find you actually get them.
