# Settings and diagnostics

Settings contains provider and application configuration. Analytics, LLM call logs, process logs and the event stream help explain what ran and what failed.

## Investigating a failed task

Read its receipt, identify the target and provider, then inspect the relevant logs. Distinguish a runner setup failure from a task failure.

## Sharing diagnostics

Include the app version, steps to reproduce and the error. Remove credentials and unrelated personal content before posting logs.
