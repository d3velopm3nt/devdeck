Two changes, nothing removed
The sidebar stays. What changes is that adding something is visible, and that the button which says it adds a project actually adds one.
1 · The header button
A bare + with a tooltip promising “a project, topic or anything else” today runs addNode(), which asks for a name and makes a folder — every time.
It becomes a labelled Add and opens the picker instead. A button that names one thing and does another is worse than no button.
2 · The workspace row
Adding to this workspace currently means right-clicking — and Add project… only appears on a solution, never on a workspace. From Develtech there is genuinely no way in.
Every workspace row gets a + on hover, opening the same picker already pointed at that workspace.
The right-click menus keep everything
New folder, Give it a bot, Workspace settings, Open terminal here, New command, New service, New profile, Reveal in File Explorer, Rename, Delete. The picker is a second way in, not a replacement — and Add project… stops being hidden on one node kind.
The one thing that is not a design change: the flow behind “a project from a folder” already exists and works — pick the repo root, it records the path and opens setup. It was only ever unreachable.
