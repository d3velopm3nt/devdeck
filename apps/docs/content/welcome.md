# Welcome to DevDeck

DevDeck brings your workspace, development tools and AI workers together. These guides help you organise your work, run your projects and review what agents produce.

> First edition: these guides describe the current development direction and code inventory. Screen names and availability may differ from your installed version. Windows and live-agent behaviour still need release verification.

## Choose a starting point

- [Set up DevDeck](#getting-started) — install the app and open your workspace.
- [Understand workspaces](#workspaces) — keep context and project code connected.
- [Run your development tools](#development) — services, commands and terminals.
- [Build a folder workflow](#workflows) — instructions, workers and reviewed steps.
- [Browse the tool directory](#tools) — find the right tool for a task.

## How the pieces fit

Your workspace holds context and work records. Linked project repositories hold application code. Workers carry out bounded tasks; managers help organise goals and work. Folder workflows describe dependencies and record review progress.

## Start with one small task

Open a workspace, connect one project, and run a familiar command. Then configure a worker for a small change before moving to a multi-step workflow.
