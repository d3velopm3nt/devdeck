# Mail, inbox and contacts

Connect mail accounts for IMAP/SMTP access. Mail credentials use Windows Credential Manager. Use Mail to read and compose messages, Contacts for people, and Inbox for items requiring attention.

## Before sending

Check the account, recipients and attachments. Agent access depends on configured permissions.

## Troubleshooting

Check account settings and the connection error. Provider-specific setup and authentication methods need verification for each account.
