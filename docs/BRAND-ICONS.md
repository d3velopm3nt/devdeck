# Brand identification icons

GitHub mark: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/github.svg), CC0-1.0.
OpenAI / ChatGPT mark: [Lobe Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/openai.svg), MIT.

Marks identify a reported sender or linked service. They do not indicate a live connection or endorsement. Monochrome SVGs inherit the current theme's text color. Ordinary UI actions continue to use the existing Lucide icon registry.
