WHY id, NOT A NUMBER

A project's id today is its SQLite row id — different on every machine. This file is committed and pulled by your team, so projects declare a slug of their own. Node ids stay local, for lookup only.

WHAT IS NOT HERE YET

No branch, no per-project state. Central storage means git no longer answers "which branch is this context for" — but add that field the day a stale context actually bites, not before.
