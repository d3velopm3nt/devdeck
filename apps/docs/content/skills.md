# Skills and agent tools

## Reusable skills

Skills provide reusable instructions. Select skills relevant to the task and keep project-specific facts in the project's context. Current workers can receive selected skills from the personal library; copies used by a runner may be placed in its working folder and excluded from Git.

## Built-in agent tool groups

| Group | Purpose |
| --- | --- |
| Files | Read and work with files within allowed scope |
| Git | Inspect and perform permitted repository actions |
| Terminal | Execute permitted commands |
| Process | Work with running processes |
| Tests | Run verification |
| Knowledge | Retrieve workspace context |
| Delegate | Hand work to another worker |
| Bots | Work with bot capabilities |
| Routines | Work with recurring routines |
| Work | Manage work records |
| Skills | Access reusable instructions |
| Memory | Maintain agent context |

The available actions depend on agent permissions and session type. Connected MCP servers can add tools; their availability depends on configuration.

## Good instructions

State the purpose, required inputs, expected outputs and verification. For example, a writing skill can define tone and editing rules while the task supplies the specific document and its constraints.
