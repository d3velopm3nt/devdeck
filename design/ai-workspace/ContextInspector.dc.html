# Offline Synchronisation — context

## Goal
Allow each TyreX site to keep operating without
internet connectivity, and synchronise cleanly
when the connection returns.

## Current state
- Local queue implemented
- Push sync implemented
- Pull synchronisation incomplete
- Conflict resolution in progress

## Rules
- The server is authoritative on conflict.
- Never trust a client timestamp for ordering.
- A queued write must survive a hard power cut.

## Open questions
- Should a queued write survive a site reinstall?
- Retention window before warning the operator?
