Lets an agent drive a real Chromium through Playwright — navigate, click, fill, and read the page's accessibility tree rather than a screenshot. Built and maintained by the Playwright team.
What it gives your bots Requirements Versions Readme Source
Twelve actions, in one tool called browser read and write are separated, so a Read grant is meaningful
Action Access What it does
browser.snapshotreadThe page as an accessibility tree, with a ref per element
browser.consolereadConsole messages since the last navigation
browser.networkreadRequests the page made, and their responses
browser.navigatewriteOpens a URL — this is the one that reaches the network
browser.clickwriteClicks an element by ref
browser.typewriteTypes into a field. It can type into a password field.
browser.file_uploadwriteAttaches a file from disk to a form
and five more writespress_key, hover, drag, select, screenshot
